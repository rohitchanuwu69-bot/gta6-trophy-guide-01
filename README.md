# Leonida Legend — GTA 6 Trophy Guide

[![GTA 6 Trophy Guide](https://make.fun/badge/gta6-trophy-guide-01.svg)](https://make.fun/bounty/gta6-trophy-guide-01)
[![Rank](https://make.fun/badge/gta6-trophy-guide-01/rohitchanuwu69-bot/gta6-trophy-guide-01/rank.svg)](https://make.fun/bounty/gta6-trophy-guide-01)
[![Reward](https://make.fun/badge/gta6-trophy-guide-01/rohitchanuwu69-bot/gta6-trophy-guide-01/reward.svg)](https://make.fun/bounty/gta6-trophy-guide-01)

An offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI: a checklist with progress saved in the browser, a guide for every trophy with sources, a five-stage roadmap to the platinum, a missables view, a Next-up planner, spoiler protection for story trophies, and progress export/import.

Every guide is written in our own words from the official trophy descriptions, with Exophase and PSNProfiles cited beside each one. How-to advice is labelled as not yet checked in-game — the game launched today — and no specific location, NPC spot or step is invented where the official description does not pin one down.

## Run it offline

```sh
node serve.ts
```

Then open http://localhost:8080 — or simply open `app/index.html` in desktop Chrome. No network requests are made at runtime.
